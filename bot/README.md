# Bot PrivateCord

Przykładowy bot do kanałów tekstowych.

1. Zainstaluj Python 3.
2. Zainstaluj zależności z `requirements.txt`.
3. Skonfiguruj poświadczenia konta usługi w pliku `config.json`.
4. Uzupełnij token w zmiennej `PRIVATECORD_BOT_TOKEN` albo pliku konfiguracyjnym.
5. Uruchom `run_bot.bat`.
