PrivateCord

Uruchom aplikację, klikając `START_PrivateCord.bat`.
Przeglądarka otworzy lokalną stronę aplikacji.

Pliki reguł i konfiguracji wdrożeniowej znajdują się w paczce.


Logo aplikacji
--------------
Plik `logo.png` w głównym folderze `PrivateCord` jest używany jako logo na ekranie logowania, ikona strony i przycisk strony głównej. Aby ustawić własne logo, zastąp ten plik swoim obrazem PNG i zachowaj dokładną nazwę `logo.png`. Zalecany obraz: kwadratowy, co najmniej 256 × 256 px, z przezroczystym tłem lub bez niego. Nie trzeba zmieniać kodu. Po podmianie odśwież stronę kombinacją Ctrl+F5.
